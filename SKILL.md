# Steps
1. At the start, create a project file (.md) under /workspace/projects/<short-slug>.md with sections: Goal, Decisions (what and why, dated PT), Rejected (options considered and why they were dropped, dated PT), Done, Next step, Open questions.
2. Save one memory note with the project name and the file's path, and say to read it first when resuming.
3. After every step or decision, update the file (keep it short; replace stale lines rather than appending forever). When a path is rejected, log it under Rejected with why, so a later resume does not retry it.
4. When resuming, read the file first instead of relying on chat history.
5. When the project is finished, mark it done, move it to /workspace/projects/archive/, and update the memory note. Offer a Page only if the user wants a nicer record.
